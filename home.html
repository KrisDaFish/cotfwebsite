the course

What you'll do, step by step

Three stages, each one building on the last — just like the code you'll write.

  1. 01

    Learn the fundamentals of programming

    This includes the logic behind programming, and the thought-processes. This part of the course will involve interactive activities so students thoroughly understand the concepts, while also having fun.

  2. 02

    Start coding in Python

    Learn how to use the logic behind coding in a practical setting. This includes learning how to convey logical operations through flowcharts and diagrams, and then later implementing these operations through Python. Using this knowledge, they will learn how to solve basic problems using code.

  3. 03

    Build your first Python project

    After learning and developing basic problem-solving skills, use these skills to make your first coding project in Python!

Absolute beginners welcome

This course is made for absolute beginners in coding and programming. It requires zero prior knowledge or experience, so don't feel intimidated.
